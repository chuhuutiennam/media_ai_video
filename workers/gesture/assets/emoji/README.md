# Demo emoji assets

Original cartoon hand/heart stickers with expressive faces, blush and a white rim,
generated from OpenCV drawing primitives by
`scripts/generate-emoji-assets.py`. No third-party artwork or fonts are included.
The icons are project assets under the same licensing terms as this worker's code.

These PNGs are 256×256 with an alpha channel. Their names match `gesture.emoji_mapping`.
Set `overlay.assets_dir` to use a different set of RGBA PNGs with the same names.
